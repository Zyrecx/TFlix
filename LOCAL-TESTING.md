# TFlix Local Desktop Testing

You can run and test TFlix 2.0 locally on your desktop browser without needing to deploy to a Samsung Smart TV.

## Quick Start

```bash
npm install
npm run dev
```

1. Open **`http://localhost:5173`** in Google Chrome or Microsoft Edge.
2. Use the arrow keys (`↑`, `↓`, `←`, `→`), `Enter`, `b` (Back), and `Space` (Play/Pause) to control the 10-foot TV interface.
3. Click the **TV Remote Simulator** button at the bottom-right corner to open the on-screen interactive remote control.

For complete details on key bindings and testing features, see [dev/README.md](dev/README.md).
